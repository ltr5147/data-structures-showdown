Timed Challenge Reflection

For the timed challenge, I chose the Balanced Symbols problem. I used a stack because brackets need to close in the opposite order from which they open. The most recent opening bracket must match the next closing bracket, which follows the last in, first out behavior of a stack. I used a Python list as the stack and a dictionary to connect each closing symbol with the opening symbol it should match. The program moves through the text once, so its time complexity is O(n). In the worst case, the stack may hold every character, making the space complexity O(n).

The 30-minute limit encouraged me to choose a direct solution instead of trying to make the program overly complicated. I first focused on the main examples, then added checks for an empty string, extra opening brackets, a closing bracket without an opening bracket, normal text mixed with brackets, and values that are not strings. Breaking the problem into those smaller cases helped me stay organized and avoid spending too much time on one part.

The main trade-off was using a regular Python list instead of building a custom Stack class. A custom class could make the stack behavior more explicit, but it would require extra code without improving the result. The list already gives O(1) append and pop operations at the end. I also chose to ignore characters that are not brackets so the function can check realistic lines of code. Under more time pressure, I might have tested only the two examples, but including edge cases made the solution more dependable without adding much complexity.
